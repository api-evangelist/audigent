# Audigent

> Data activation, curation and identity platform for digital advertising, acquired by Experian in December 2024. Audigent operates the Hadron ID cookieless identifier and the SmartPMP / ContextualPMP / CognitivePMP private-marketplace suites. Its public technical surface is not a documented REST developer program — it is a set of live browser-side identity, segment and analytics endpoints on the ad.gt and hadronid.net domains, reached through three first-party open-source Prebid.js modules that Audigent authors and maintains upstream.

Provenance: this file was GENERATED by API Evangelist from probed public sources on 2026-08-06.
Audigent does not publish an llms.txt of its own (/llms.txt 404s on every API host and
soft-404s on audigent.com). This is a third-party profile, not an Audigent document.

## Important caveats for agents

- **audigent.com and dev.audigent.com return HTTP 200 for every path**, redirecting to
  /index.html. A 200 from those hosts is NOT evidence that a page exists. Diff any response
  against a control path before trusting it.
- **There is no OpenAPI, Swagger, GraphQL, AsyncAPI or MCP surface.** /openapi.json,
  /swagger.json, /api-docs, /.well-known/api-catalog, /.well-known/oauth-authorization-server
  and /.well-known/openid-configuration all 404 on every Audigent and Hadron host.
- **There is no A2A agent card.** /.well-known/agent-card.json and /.well-known/agent.json
  404 everywhere.
- **There is no SDK on any package registry.** Integration is a Prebid.js build flag or a
  hosted script tag.

## APIs

- [Hadron ID API](https://id.hadron.ad.gt/api/v1/pbhid): Public, anonymous, unauthenticated
  GET returning JSON with `hadronId`, `hadronIdv2`, `haloId` and `cf`. Query parameters:
  `partner_id`, `_it`, `src`, `t`, `domain`, `debug`, plus consent signals `gdpr`,
  `gdprString`, `us_privacy`, `gpp`, `gpp_sid`. CORS is fully open. Verified live 2026-08-06.
- [Hadron RTD API](https://seg.hadron.ad.gt/api/v1/rtd): Returns an OpenRTB `ortb2` fragment
  of Audigent audience segments and contextual signals for merging into a Prebid auction.
  Requires an Audigent-issued numeric `partnerId`.
- [Hadron Analytics API](https://analytics.hadron.ad.gt/api/v1/analytics): Prebid auction
  telemetry collection endpoint. Accepts GET, POST and OPTIONS.
- [UID2 / Hadron resolution](https://uid2.hadron.ad.gt/v1/hadron.json): JSON identity
  resolution used by the hadron.js bundle for UID2 interoperability.
- [Legacy Halo cookie match](https://ids.ad.gt/api/v1/halo_match): Still live; answers 202
  with a tracking GIF rather than JSON.
- [Audigent Platform API](https://api.audigent.com): Authenticated console API. Every
  anonymous request 302s to https://admin.audigent.com. No public reference is published.

## Authentication

There is no API key, token or OAuth flow. The public endpoints take a non-secret numeric
`partner_id` issued during onboarding and visible in page source. The platform API is gated by
a console session at admin.audigent.com. See authentication/audigent-authentication.yml.
